# Русификация Hermes Desktop — workflow (пошаговый промпт для LLM)

Цель: при каждом обновлении Hermes довести русскую локализацию до состояния
«переведено всё осмысленное, сборка проходит, UI на русском».

Корень установки: `D:\NEURO\Hermes`. Источник переводов: `scripts\ru-locale\ru.ts`.

---

## Инварианты (нарушение = сломанный Desktop)

1. **Шапка и хвост `ru.ts` неизменны:**
   ```
   import { defineLocale } from './define-locale'
   import { RU_FIELD_DESCRIPTIONS, RU_FIELD_LABELS } from '@/app/settings/ru-constants'

   export const ru = defineLocale({
   ...
   })
   ```
2. `ru.ts` — **оверрайды** поверх `en.ts` (`mergeTranslations(en, overrides)`), а не полный словарь:
   непереведённое автоматически берёт английский текст. **Пустые в en ключи переводить не нужно.**
3. **Существующие переводы неприкосновенны.** LLM правит только отсутствующие ключи
   (импорт с `--only-new`). Менять уже переведённое — только при явном смысловом расхождении
   и с подтверждением владельца.
4. **Порядок ключей — как в `en.ts`** (нужен для построчного WinMerge).
5. TS-приведения (`} as Record<string, string>,`), функции (`count => ...`), массивы и шаблонные
   строки переносятся как есть, не пересоздаются.
6. Ключи с дефисом — только в кавычках (`'local-runtime-update': {...}`).
7. Плоский стиль группы сохраняется: если у соседей ключи вида `'view.toggleHud'`,
   новый ключ тоже пишется плоско, а не объектом.

---

## Шаги

**0. Предусловие.** `scripts\en-locale\en.ts` — актуальная копия из репозитория Hermes
(обновляет `scripts\InstallOrUpdate-RU.bat` шаг 2 или `Rebuild-Desktop.bat`).

**1. Отчёт и выровненная пара.**
```
python scripts\py\compare_i18n_keys.py                     # непереведённые / осиротевшие / идентичные
python scripts\py\compare_i18n_keys.py --flatten data\temp\i18n-compare
```
В `data\temp\i18n-compare\`: `en.flat` и `ru.flat` — **построчно 1:1, порядок как в en.ts**;
`<НЕТ ПЕРЕВОДА>` справа = строки нет в `ru.ts`; `missing.flat` — готовый список для перевода.
Смотреть в WinMerge: `Tools.bat` → `[1]` (выровненные списки) или `[2]` (исходники en.ts/ru.ts).

**2. Перевод (LLM пошагово).** Переводить только строки с `<НЕТ ПЕРЕВОДА>`
(и, по согласованию, кандидатов из `--same` — где ru совпал с en, но это обычное слово,
а не бренд). Результат — файл формата `ключ = русский текст`, одна строка на ключ;
переносы внутри текста — литерально (`\n`).

**3. Импорт в источник.**
```
python scripts\py\i18n_apply_flat.py --flat <файл> --ru scripts\ru-locale\ru.ts --only-new
```
`--only-new` не трогает существующие переводы. Для осознанных правок существующих — без флага,
предварительно просмотрев выведенный список «Изменённые переводы». Делается `.bak`.

**4. Выравнивание порядка.**
```
python scripts\py\i18n_sort_like_en.py
```
Ждём «Проверка пройдена: ключей N (до и после идентичны)». Скрипт переносит фрагменты
(значения/функции/массивы не пересоздаются) и правит порядок; копия — `ru.ts.pre-sort`.

**5. Проверка (ядро workflow).**
```
python scripts\py\i18n_verify.py
```
Проверяет: структуру (ключи, нет мусорных ключей), **esbuild-синтаксис** `ru.ts` и `ru-constants.ts`,
порядок как в en, сводку. Должно быть «ИТОГ: проверка пройдена» (exit 0).
То же — `Tools.bat` → `[8]`.

**6. Сборка.**
`scripts\Tools.bat` → `[5]`: бэкап (файлы локализации + готовая сборка) → **esbuild-проверка** →
`Rebuild-Desktop.bat` (копирует `ru.ts` в `i18n\`, патчит `types/languages/catalog`,
`npm install` + `npm run pack`) → запуск Desktop.
При сбое — `Tools.bat` → `[6]`: откат файлов и сборки из `data\backup\` (без пересборки).

**7. Цикл.** Если `verify` или сборка не прошли — исправляем и повторяем с шага 3,
пока `i18n_verify.py` не вернёт exit 0, а сборка не завершится успешно.

---

## Критерии готовности

- `i18n_verify.py` → exit 0 (структура + esbuild + порядок).
- `Tools.bat [5]` → сборка успешна, Desktop запускается, UI на русском.
- Непереведёнными остаются только ключи с **пустым** значением в `en.ts`.

## Откат (если «котяха»)

- `Tools.bat [6]` — файлы локализации + собранный Desktop из `data\backup\`.
- Локальные копии: `scripts\ru-locale\ru.ts.bak` (до импорта), `ru.ts.pre-sort` (до выравнивания).

## Инструменты (все — `scripts\py\`)

| Скрипт | Назначение |
|---|---|
| `compare_i18n_keys.py` | сравнение ключей en/ru: непереведённые, осиротевшие, идентичные; `--flatten` — выровненная пара |
| `i18n_apply_flat.py` | импорт переводов в ru.ts (`--only-new`, `--prune`, `--dry-run`, `--out`) |
| `i18n_sort_like_en.py` | порядок ключей как в en.ts |
| `i18n_verify.py` | быстрая проверка (структура + esbuild + порядок) |
| `ru_locale_backup.py` | бэкап/откат (файлы + сборка) |
